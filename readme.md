# Key Prefixer
Simple mod that adds a prefix to a list of keys. Just like reserve already has. 
List of keys and prefixes can be expanded, and technically works on any items not just keys.
Has support for WTT-Backport and Icebreaker keys, but can support any keys from any mod in theory.

## Requirements
- [Leaves-LeavesUtil](https://github.com/DeadLeavez/Leaves-LeavesUtil) ([latest release](https://github.com/DeadLeavez/Leaves-LeavesUtil/releases/latest)) - required.

## Planned Features
